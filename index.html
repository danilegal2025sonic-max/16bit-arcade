ARQUIVOS DE SISTEMA

As BIOS são opcionais para Game Boy, Game Boy Color, GBA, Master System e Game Gear, e ficam só neste aparelho. PS1 depende de uma BIOS compatível; Nintendo DS exige bios7.bin, bios9.bin e firmware.bin; ColecoVision e 3DO exigem BIOS; Atari Lynx e 7800 aceitam BIOS opcional. Dreamcast usa dc_boot.bin e dc_flash.bin; jogos de CD da PC Engine podem precisar de BIOS; Amiga pode precisar de Kickstart. A BIOS é usada junto de uma ROM: este núcleo não inicia sem jogo. PS2 e PS Vita abrem soluções externas; o Vita3K oficial é outro app.
